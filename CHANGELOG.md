# Changelog

## 1.1.0 — System-aware update

- Smoothened long-screen scrolling with stable LazyColumn keys/content types and preserved list state.
- Added Android system/dynamic colours, including automatic dark mode while Battery Saver is active.
- Fixed date consistency: past and future food logs now retain the selected date and use date-aware intake labels.
- Added edit flows for food, water, and weight entries.
- Deleting the latest weight measurement now restores the previous measurement in the profile summary.
- Added clear-cache controls and user-visible export success/failure messages.
- Added custom serving units: grams, millilitres, pieces, cups, and bowls.
- Added an ingredient-based custom recipe builder with calculated macros.
- Added a Room migration that preserves existing custom foods and logs.
- Updated the app version to 1.1.0.
